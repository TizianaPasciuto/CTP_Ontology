| Syntax of the mapping              | Meaning                                                                                                                                                                                                 |
|------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| --                                 | not directly mappable                                                                                                                                                                                  |
| xxx/                               | the URI or value of xxx reachable via xxx                                                                                                                                                              |
| <URI> (comment)                    | actual URI to use, and comment explains what the URI refers to                                                                                                                                         |
| xxx[yyy]/                          | the entity reachable via xxxx, restricted to the expression yyyy                                                                                                                                       |
| xxx/zzz/hhh/                       | property chain connecting xxx to entities reachable via zzz/hhh                                                                                                                                        |
| xxx(zzz[yyy])/                     | the entity _b1 reachable via xxx, where _b1 has entities matching the expression yyy; for example, _b1 is connected via zzz with the type yyy                                                         |
| xxx/zzz*/hhh/                      | property chain connecting xxx via zzz/hhh, where zzz can appear in the chain zero or one time                                                                                                          |
| xxx/(zzz\|hhh)/                    | property chain indicating xxx/zzz/ or xxx/hhh/                                                                                                                                                          |
| /id=Term(Controlled Vocabulary)    | entity having id (namely URI) corresponding to the URI of the Term taken from the indicated controlled vocabulary                                                                                     |
| /id=Term                           | entity having id (namely URI) corresponding to the URI of the Term taken from the Getty controlled vocabulary                                                                                          |
